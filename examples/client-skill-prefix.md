# Optional guidance — not an integration mechanism

This archived prefix is not required for native activation. Use the installed
server binding and client hooks in `docs/client-compatibility.md`. Adding these
words to a skill does not implement or prove automatic enforcement.

This skill participates in the operator-provisioned SkillFlow case supplied to
your session. Read `flow_status` before work and `skill_read` for the exact approved
instructions. Submit final UTF-8 bytes through `artifact_submit`; run required
`flow_check` steps, request review, and use `delivery_request` when ready.

Keep the returned case ID, invocation ID, revision and idempotency key. After a
context reset, reread server state. A summary cannot restore prior validations.
Report missing controls and source failures instead of claiming success.

You hold only writer authority. Do not impersonate a connector, reviewer or human
operator. A hook shares its actual account and credentials. Only exact artifacts
exported by the configured gate have the corresponding receipt; free chat text
and native output files do not automatically receive that status.

This prefix is guidance. The dossier, controller and tested operating-system
rights establish the actual obligation and covered boundary.
