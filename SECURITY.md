# Security policy

The 0.1.0 alpha is the current development line. It has no generally validated
production protection profile. Demo is explicitly unprotected. Read the threat model.

Report suspected vulnerabilities privately to **cherridsaid@gmail.com**. Include
version/commit, mode, a minimal synthetic reproduction and observed effect.
Exclude real credentials, documents and personal data. This maintainer contact
is supplied for the project; no response deadline is guaranteed. Do not post
secrets or full exploit details in public issues.

GitHub private vulnerability reporting has **not been enabled or verified**:
the public repository is not created. Enable it after publication approval,
then update this policy. Until then use the email above.
[GitHub guidance](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/add-security-policy).

Dependency updates, key rotation and expanded execution coverage need fresh tests.
Passing CI is not evidence of Windows ACL protection.
